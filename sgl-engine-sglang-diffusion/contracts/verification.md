# Verification contract

- Freeze the baseline once and never remeasure it inside candidate work.
- Count one scientific round as one hypothesis, one candidate, one complete
  real run, and one verification gate.
- Edit only the assigned isolated worktree. Preserve the frozen workload and
  timing scope, and provide an OFF path that restores source-current behavior.
- Judge lossless kernel and topology candidates by mathematical equivalence,
  unchanged global denoising-step and model-call counts, and unchanged logical
  work. Do not allow approximation, sparsity, step skipping, reduced precision,
  or rank reduction.
- Never reject a lossless candidate using output differences, LPIPS, PSNR,
  floating-point tolerances, or visual quality. Use output media only to prove
  that the complete run is authentic.
- Require quality-gated cache, sparse-attention, quantization, and
  token-pruning candidates to provide aligned LPIPS, built-in five-prompt
  visual review, positive engagement, and the complete frozen workload.
- Do not use an external vision API for the visual verdict.
- Retain only points backed by durable run, media, frame, benchmark,
  assessment, implementation-manifest, source-hash, and provenance artifacts.
- Reject activations without positive engagement or with disallowed fallback.
- Recompute performance and verify provenance, authenticity, quality, and the
  actual method before integration.
- Integrate only verified frontier points and rerun the complete frozen
  workload. Apply the quality gate to a composed stack if any selected
  technique is quality-gated.

Meeting a stretch target never substitutes for the applicable gate. Missing a
stretch target does not prove that the target is theoretically unreachable.
