# Pi0.5 action diffusion flow

覆盖 `lerobot/pi05_base` 与 `lerobot/pi05_libero_base`。这是 VLA action API，不是
图像/视频生成，没有可复用 VAE；优化对象是 PaliGemma prefix、action expert 和
10-step action denoise。

```bash
hf download lerobot/pi05_base --local-dir /data/models/pi05_base
sglang serve --model-path /data/models/pi05_base --host 127.0.0.1 --port 30010
curl -s http://127.0.0.1:30010/v1/actions/metadata

# 仓内 action E2E/consistency/perf harness（会生成三路确定性 camera 输入）：
SGLANG_RUN_PI05_E2E=1 \
SGLANG_PI05_E2E_MODEL=/data/models/pi05_base \
SGLANG_PI05_E2E_NUM_STEPS=10 \
SGLANG_PI05_E2E_PERF_WARMUP=20 \
SGLANG_PI05_E2E_PERF_REPEAT=100 \
SGLANG_PI05_E2E_PERF_DUMP="$BENCH_DIR/pi05-baseline.json" \
pytest -q python/sglang/multimodal_gen/test/single_test_file/test_pi05_e2e.py
```

基准请求固定 task、三路 224x224 camera、32-d state、action horizon 50、action dim
32、10 steps；请求 JSON/msgpack schema 以
`python/sglang/multimodal_gen/test/unit/test_pi05_action_api.py` 为准，不手写漂移字段。

1. 分离 image preprocess/vision tower、PaliGemma prefix、prefix cache、action expert
   denoise、action head 与序列化。
2. 跑 [`../components/encoders.md`](../components/encoders.md)、DiT 和 distributed
   flow；不执行任何 VAE flow。
3. 扫 prefix cache、action CUDA graph、prefix TP/action SP 与合法 offload；动态 batch
   同时报告 p50/p95、throughput、peak memory。
4. correctness 比较 action shape/有限值、normalized MSE/cosine，并在 replay 数据上
   报任务指标；cache on/off、不同 camera/state/task 和连续 session 必须一致。
5. `pi05_base` 与 LIBERO checkpoint 分别 smoke；禁止用生成图像指标验 action policy。
